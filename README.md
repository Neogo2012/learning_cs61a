## Test Commands

The tests are run using the `ok` autograder. Use the following commands:

- `python ok -q <question_name> --local` – run a specific test question
- `python ok --score --local` – get your total score

The `--local` flag is essential for independent learners (those not using a school account). Without it, the tests will prompt for school login credentials and fail. The commands listed on the official CS 61A website do not include `--local` by default, so they will not run successfully for online learners.
